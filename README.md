# Spellbrawl

เกมการ์ดสร้างเด็ค (deck-building) พ่อมดตีกัน เล่นกับ AI 1–4 คน ได้แรงบันดาลใจจากบอร์ดเกมสร้างเด็คแนวพ่อมดตีกัน
ชื่อการ์ด ข้อความ และตัวละครทั้งหมดเป็นของที่สร้างขึ้นใหม่

## วิธีเล่น

เปิด `index.html` ในเบราว์เซอร์ (Chrome, Edge, Safari) ไม่ต้องติดตั้งอะไร

- Windows: ดับเบิลคลิก `index.html`
- macOS: `open index.html`

## ใส่ภาพ

วางไฟล์ในโฟลเดอร์ `art/` (ใช้ได้เมื่อเปิดจากไฟล์ในเครื่อง)

- พื้นหลังกระดาน: `art/board.jpg` (หรือ `.png`, `.webp`)
- พรมใต้แผงของคุณ (มือ สัตว์รับใช้ บันทึก): `art/mat.jpg` (หรือ `.png`, `.webp`)
- ภาพการ์ด: `art/<รหัสการ์ด>.png` หรือ `.jpg` เช่น `art/fireball.png`
  ดูรหัสการ์ดได้ที่ปุ่ม "ภาพกระดาน/การ์ด" ในเกม

หรืออัปโหลดภาพผ่านปุ่ม "ภาพกระดาน/การ์ด" ในเกม (เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น)
