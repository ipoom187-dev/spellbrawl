# Wizard Royale

เล่นบนเว็บ: https://ipoom187-dev.github.io/wizard-royale/

ในโลกนี้มีการแข่งขันหาพ่อมดที่เก่งที่สุด และคุณคือหนึ่งในผู้เข้าแข่งขัน

เกมการ์ดสร้างเด็ค (deck-building) พ่อมดตีกัน เล่นกับ AI 1–4 คน หรือเล่นออนไลน์กับเพื่อนคนละเครื่อง (2–5 คน เติม AI ได้) ได้แรงบันดาลใจจากบอร์ดเกมสร้างเด็คแนวพ่อมดตีกัน
ชื่อการ์ด ข้อความ และตัวละครทั้งหมดเป็นของที่สร้างขึ้นใหม่

## วิธีเล่น

เปิด `index.html` ในเบราว์เซอร์ (Chrome, Edge, Safari) ไม่ต้องติดตั้งอะไร

- Windows: ดับเบิลคลิก `index.html`
- macOS: `open index.html`

## เล่นออนไลน์กับเพื่อน

1. คนหนึ่งเปิดเกมจากเว็บ (GitHub Pages) กด **สร้างห้อง** จะได้รหัสห้องและลิงก์
2. ส่งลิงก์ให้เพื่อน เพื่อนเปิดแล้วใส่ชื่อ กด **เข้าห้อง** (หรือกด "เข้าห้องเพื่อน" แล้วพิมพ์รหัส)
3. เจ้าภาพเลือกว่าจะเติม AI กี่ตัว แล้วกด **เริ่มเกม**

เกมรันบนเครื่องเจ้าภาพ เจ้าภาพต้องเปิดหน้าเกมค้างไว้จนจบ ถ้าเพื่อนหลุด AI จะเล่นแทนจนกว่าจะเข้าห้องเดิมอีกครั้ง
เชื่อมต่อผ่าน WebRTC (PeerJS) ไม่ต้องสมัครอะไร บางเครือข่าย (เช่น Wi-Fi บริษัท/มหาลัยบางที่) อาจบล็อกการเชื่อมต่อแบบนี้

## ใส่ภาพ

วางไฟล์ในโฟลเดอร์ `art/` (ใช้ได้ทั้งตอนเปิดจากไฟล์ในเครื่องและบนเว็บ)

- พื้นหลังกระดาน: `art/board.jpg` (หรือ `.png`, `.webp`)
- พรมใต้แผงของคุณ (มือ สัตว์รับใช้ บันทึก): `art/mat.jpg` (หรือ `.png`, `.webp`)
- ภาพการ์ด: `art/<รหัสการ์ด>.png` หรือ `.jpg` เช่น `art/fireball.png`
  ดูรหัสการ์ดได้ที่ปุ่ม "ภาพกระดาน/การ์ด" ในเกม

หรืออัปโหลดภาพผ่านปุ่ม "ภาพกระดาน/การ์ด" ในเกม (เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น)
